# Publication checklist

[ ] Create public repository `MasynNay/between-the-lines` (one-time step)
[ ] Upload only the PUBLIC_DEMO site files from this ZIP, including `.github/workflows/pages.yml`
[ ] Confirm GitHub Actions workflow is green
[ ] Select GitHub Actions as Pages source
[ ] Set GitHub Pages custom domain to `btl.masynnay.com`
[ ] Confirm Cloudflare `btl` CNAME target is `masynnay.github.io` and DNS only while validating
[ ] Enable HTTPS once certificate is available
[ ] Verify desktop and mobile in a regular browser
[ ] Verify demo/ link, question citations, locked chapter boundaries, theme options, reset
[ ] Confirm full application ZIPs, PDFs, accounts, and Ollama models are NOT in public repo

The domain is **not live** until GitHub Pages is configured and deployment succeeds.
