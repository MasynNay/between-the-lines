# Public demo transparency

**What visitors can test:** two original short stories, switching books, setting reading progress, spoiler-aware character appearance, chronological relationship citations, authored question prompts, literal source search, ten themes, and resetting the demo.

**What visitors cannot test here:** a real account, uploading a novel, actual PDF import, live Ollama inference, book-wide model comprehension, or production data isolation. These require the private local application.

This static demo has no analytics or backend requests. Reading progress and theme are remembered in browser localStorage only. The site contains historical screenshots from an earlier build, clearly labeled as such, and wholly original demo story prose. This distinction is maintained on the landing page, within the reading room, and in the README.

For production launch of the actual self-hosted application, review authentication security, rate limits, file upload isolation, model resource caps, and user-data policies independently. Do not use this demo as a substitute for such an audit.
